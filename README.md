# Virtual Try-On

A web app that generates a 3D avatar of the user and lets them visualize recommended
fashion items and styles on that avatar before buying.

## Status

🚧 Early development — project scaffolding.

## What it does (goal)

1. Build a 3D avatar from the user's body measurements (and optionally photos).
2. Recommend fashion items and complete styles based on the user's preferences.
3. Render those items on the avatar so the user can see, rotate, and compare looks.
